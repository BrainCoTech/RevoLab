# Security reporting

For security issues, use the [BrainCo support channel](https://web.static.brainco.cn/work-order)
to request a private contact for RevoLab. Include the affected version and
reproduction steps through that private channel; keep credentials and exploit
details out of public issues.

Ordinary bugs and installation questions belong in
[GitHub issues](https://github.com/BrainCoTech/RevoLab/issues), following
[CONTRIBUTING.md](CONTRIBUTING.md).
