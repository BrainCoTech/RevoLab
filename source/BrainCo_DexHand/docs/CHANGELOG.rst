Changelog
---------

0.2.0 (unreleased)
~~~~~~~~~~~~~~~~~~

Changed
^^^^^^^

* Migrated to the pinned 20261014 brainco-description submodule and v1 task IDs.
* Removed obsolete v0 robot assets, policies, caches and demos; added asset
  contracts for resumption, evaluation and export.
* Corrected Lift and Handover initial scenes for the new arm and hand assets.
* Completed the six-task simulation demo campaign; HORA results cover Stage 1.
* Added colored rotation visuals without changing object collision geometry.
* Documented the pinned runtime, validation commands and third-party licenses.

Hardware deployment and pretrained weight publication remain pending.

0.1.0 (2026-04-13)
~~~~~~~~~~~~~~~~~~

Added
^^^^^

* First public release of the BrainCo Isaac Lab task subset.
* Added public task naming aligned with the BrainCo open-source convention.
* Packaged pretrained checkpoints, README, license, and third-party notices.
